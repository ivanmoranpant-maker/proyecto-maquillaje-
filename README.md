# proyecto-maquillaje-

Página web publicitaria de venta para **HUMIDE Serum Concealer** de MONTOC.

Diseño minimalista en tonos crema y suaves, pensado para un público femenino.

## Contenido

- `index.html` — estructura de la página (hero, beneficios, descripción, selector de 11 tonos, testimonios y sección de compra).
- `css/styles.css` — estilos (paleta crema/blush/terracota, tipografías serif + sans, animaciones al hacer scroll).
- `js/script.js` — lógica de los 11 tonos, selector interactivo, menú móvil y formulario de compra.

## Cómo verla

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8080
```

y visita `http://localhost:8080`.
